# 📝 Personal To-Do List

A simple and responsive **Personal To-Do List web application** built using **HTML, CSS, and JavaScript**.
The application helps users create, manage, track, and complete their daily tasks.

## 🌟 Features

* 🔐 User Sign Up and Login
* 🔑 Forgot Password option
* 📝 Create new tasks
* 📋 View all tasks
* ⏳ Track task status
* 📊 Dashboard with task statistics
* 📈 Progress percentage and progress bar
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📜 View completed task history
* 👤 Profile page
* ✏️ Update profile information
* 🚪 Logout option
* 💾 Data stored using Browser Local Storage
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – For creating the structure of the web pages
* **CSS3** – For styling and responsive design
* **JavaScript** – For task management and application functionality
* **Local Storage** – For storing user and task data in the browser

## 📄 Pages

### 🏠 Home

The Home page contains the main dashboard where users can:

* View total tasks
* View pending tasks
* View in-progress tasks
* View completed tasks
* Check overall progress
* Create new tasks
* Complete or delete tasks

### 👤 Profile

The Profile page allows users to:

* View their profile information
* Update their name and email
* Logout from the application

### 📜 History

The History page displays tasks that have been completed.

### 🔐 Login

Users can log in using their registered email and password.

### 📝 Sign Up

New users can create an account by entering their name, email, and password.

## 📊 Dashboard

The dashboard provides an overview of the user's tasks:

| Section        | Description                             |
| -------------- | --------------------------------------- |
| 📋 Total Tasks | Shows the total number of tasks         |
| ⏳ Pending      | Shows tasks that are not completed      |
| 🔄 In Progress | Shows tasks currently in progress       |
| ✅ Completed    | Shows completed tasks                   |
| 📈 My Progress | Shows the percentage of completed tasks |

## 💾 Data Storage

This project uses **Browser Local Storage** to store:

* User information
* Login status
* Tasks
* Task status
* Completed task information
* Profile information

The data remains available in the same browser unless the browser's stored data is cleared.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `login.html`.
4. Open the file in a web browser.
5. Create a new account.
6. Log in to the application.
7. Start creating and managing your tasks.
